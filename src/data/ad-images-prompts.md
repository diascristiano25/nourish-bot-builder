## 📐 Especificações Técnicas

### Formatos Recomendados

**Feed (Quadrado)**
- Dimensão: 1080x1080px
- Formato: JPG ou PNG
- Tamanho: < 30MB
- Texto na imagem: < 20% da área

**Stories (Vertical)**
- Dimensão: 1080x1920px
- Formato: JPG, PNG ou MP4
- Duração vídeo: 15 segundos max
- Safe zone: 250px top/bottom

**Feed (Landscape)**
- Dimensão: 1200x628px
- Formato: JPG ou PNG
- Ideal para: Links compartilhados
- Texto: < 20% da área

## ✅ Checklist Pré-Upload

Antes de subir cada imagem no Meta Ads:

- [ ] Dimensões corretas (1080x1080 ou 1200x628)
- [ ] Texto < 20% da área (usar Meta Text Overlay Tool)
- [ ] Logo NutriFlow visível (canto inferior direito)
- [ ] Contraste suficiente (legível no mobile)
- [ ] Arquivo < 30MB
- [ ] Formato JPG (melhor compressão)
- [ ] Preview em mobile e desktop
- [ ] Rostos de pessoas sem direitos autorais (ou usar Midjourney)

## 🚀 Geração em Massa

### Usando Midjourney (Recomendado)

1. Entre no Discord do Midjourney
2. Use `/imagine` com os prompts acima
3. Para variações: clique em V1, V2, V3, V4
4. Para upscale: clique em U1, U2, U3, U4
5. Para ajustes finos: use `--stylize 500` ou `--chaos 10`

### Usando DALL-E 3 (via ChatGPT Plus)

1. Cole o prompt
2. Adicione "professional marketing photography"
3. Gere 2-4 variações
4. Baixe em alta resolução

### Edição Final (Figma/Canva)

1. Adicionar logo NutriFlow
2. Ajustar cores para match da marca
3. Adicionar elementos de texto se necessário
4. Exportar em 2x (Retina)
